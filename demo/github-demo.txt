== 1. Register GitHub as a provider (the secret goes to OpenBao only)
$ curl -X POST http://localhost:8080/providers -d '{"name":"github","provider":"github","client_id":"Ov23liDMCs2F9DxLzLqY","client_secret":"<from .env, not shown>"}'
{
  "name": "github",
  "provider": "github"
}

== 2. Connect user 'demo-user': get the GitHub authorization URL
$ curl -X POST http://localhost:8080/providers/github/users/demo-user/connect
https://github.com/login/oauth/authorize?client_id=Ov23liDMCs2F9DxLzLqY&redirect_uri=http%3A%2F%2Flocalhost%3A8080%2Fcallback&response_type=code&scope=read%3Auser&state=O9JoGGVIIXw5sQ-sxpXY95SLZ8nLVdNz5F39HYSGy8I

Opening it in your browser — approve the app on GitHub.
GitHub then redirects the browser to http://localhost:8080/callback, where OpenBao exchanges the code.
(if no browser window opened, copy the URL above into one)
Press Enter once the browser shows {"status":"connected",...}

== 6. The service never stores tokens itself
Tokens live only in OpenBao (oauth2/creds/github/demo-user); the service keeps
request results in memory for 5 minutes. A user who never connected:
{
  "status": "failed",
  "error_code": "not_connected",
  "error": "user 'nobody' has not connected 'github'"
}
